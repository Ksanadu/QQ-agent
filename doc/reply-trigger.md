# 准确引用机器人消息直接召唤（2026-10-29）

群聊 1～3 档中，准确引用机器人本人发出的 QQ 消息，与 @ 一样按 1 档触发，原因显示为“引用机器人消息”。不依赖一分钟关联监听是否存在，也不要求正文命中关键词。4 档仍全部响应，私聊仍恒响应。

判定使用宿主解析的 reply 快照：必须解析成功、标记为机器人发言、发送者 QQ 号等于当前机器人账号，并有合法的非零安全整数消息 ID（支持负数）。按原消息 ID 从同会话存档或协议端读取；无法读取、消息 ID/会话对不上、引用其他人、只在正文手写引用格式都不算。昵称和引用原文不用于认定机器人身份。

原有入口判定、运行后 drain 补判定共用 resolveContextTier，因此都支持此条件。暂停、白名单等闸门继续生效。指令禁言仍禁止关联监听，但准确引用现在与 @ 同属直接召唤，可以触发。

验收：node test/reply-trigger-e2e.mjs；隔离数据目录、模拟 OneBot 与模型，不向真实 QQ 群发测试消息。覆盖档位、真实引用解析、来源失败与身份误判、无监听、发送队列、老实模式及运行期间到达的引用。
