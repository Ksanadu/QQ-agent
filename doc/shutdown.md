# 从控制台停机

点击右上角 **停机**，确认后查看实时停机日志：

1. 中止当前任务，不再接收新的处理任务。
2. 停止本实例 SnowLuma 及其子进程，检查配置的 HTTP、WebSocket 和 WebUI 端口。
3. 保存 QQ-Agent 会话状态，停止该部署的进程树，检查控制台端口。
4. 成功后倒计时 3 秒，尝试关闭当前浏览器标签页。浏览器禁止关闭时，页面显示“已停机，可手动关闭此标签页”。

停机失败时保留日志，不自动关闭页面。完整日志位于数据目录的 `logs/shutdown-时间戳.log`。重新运行原有启动或重启入口即可恢复服务。

仅支持 Windows 本机 SnowLuma。程序按进程身份和父子关系清理，不按端口强杀陌生进程，保留用户已登录的 QQ。独立停机助手在主服务退出后继续提供最终日志，成功后 10 秒退出；失败后保留 60 秒供页面读取。日志助手只监听本机回环地址，使用本次操作随机令牌并验证页面来源。

运行 `npm run test:shutdown` 验证确认/取消、失败日志、进程归属、端口检查及真实隔离进程树退出。测试不会停止实际机器人。
