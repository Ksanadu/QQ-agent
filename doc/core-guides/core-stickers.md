# 表情包、消息贴表情与拍一拍

## 选择与发送表情包

表情目录不再自动附带。需要时用 list_stickers 查询真实收藏 ID、备注与标签，没备注或不确定含义先 get_sticker_image 看图，不猜内容。闲聊可从“随便发”池选，回击从“怼人”池选，轮换使用。send_sticker 每条一张、独立气泡；同时要说话可并用 send_message。严肃场景不硬塞表情。

频率取读取结果 runtime.stickerEncourage：0=极少（<10%）；1=偶尔（约20%~30%）；2=适度（约50%）；3=积极（约75%~80%）。都不是每次必发，不连续刷同一张。这是表情选择设置，不覆盖角色卡的回复风格。

收藏聊天里的图片用 collect_sticker，保留真实源消息 ID，随后看图、补备注和统一标签。大规模整理、盘点或删除收藏表情，另读 sticker-librarian 速查；审批未通过不能说已删除。

## 消息右键贴表情

react_message 只允许【本轮可贴表情的消息】列出的固定 ID：本轮触发批＋首条触发之前最近10条同会话记录。引用不扩大窗口，运行中新消息、其他会话和转发内部消息也不加入。

按发送者和上下文选目标；用户指定别人的消息时不能换成请求者。对象不在窗口或无法定位就说明/请其重发，不擅自代替目标。指定表情不受支持时也应说明，不擅换其他表情。通常每条一个、整轮少量；贴表情不能替代文字交付，必须先用 send_message 向当前聊天发送成功后才能完结。文字应回应实际请求，不必机械汇报“已贴表情”。宿主仍强制校验窗口、枚举和发送权限。

## 拍一拍

send_poke 可回应 [拍一拍]，也可偶尔拍正在聊天的人或熟人，不频繁使用；群聊目标用准确 QQ 号，无法定位先查询。
