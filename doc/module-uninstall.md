# 卸载技能与插件

在「技能与插件」中点击条目右侧的 **卸载**，再点击 **确认卸载**。

默认保留配置与数据：模块停用、注销工具及能力，并从安装目录移走。配置保留为停用状态，主数据目录内的数据保持原位。完整模块目录（包含模块自行存放的文件）保存在数据目录的 `module-backups/skills或plugins/目录名/随机编号/module`，不再被加载。若要手动恢复，停机后将该目录移回原来的安装位置，再启动并启用模块。

打开 **同时清理配置与本地数据** 后，会额外确认不可恢复的删除。清理范围包括该模块的配置段、模块目录与此前的卸载备份、`data/skills或plugins/模块ID`，以及现有模块的专属数据：API 生图缓存与额度、Comfy 工作流与缓存、跨群记忆曲线、TTS 缓存与本地引擎。不会删除共享聊天记录、主记忆库、外部 ComfyUI 服务或网易云服务的数据。

第三方模块若自行将文件写到其他位置，卸载器无法确定其所有权，这些外部文件仍需按该模块说明处理。

卸载与热重载串行执行，卸载过程中暂停目录监听，完成后刷新工具列表。失败时显示原因；文件无法移走时保持停用，不报告卸载成功。
