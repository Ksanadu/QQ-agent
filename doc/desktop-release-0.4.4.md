# QQ Agent Desktop 0.4.4

独立桌面控制台：保留现有 0.4.2 机器人后台，用 0.5.1 的视觉设计与桌面外壳呈现控制台，原 Web 界面不换皮。

## 下载与安装

下载附件 `QQ-Agent-Desktop-0.4.4-Setup.exe`，适用于 Windows x64，安装器未签名。

先启动现有 0.4.2 机器人后台，再打开 **QQ Agent Desktop**；默认连接 `http://127.0.0.1:3210`，可在顶部更换本机后台地址。此安装包只包含桌面控制台，不包含机器人后台、QQ 或 SnowLuma。

更新已有独立桌面时，选择原来的 **QQ Agent Desktop** 安装目录。桌面偏好保存在 `%APPDATA%/QQ Agent Desktop/desktop-preferences.json`，升级保留；机器人配置和数据继续使用原后台目录。

## 桌面变化

- 暖炭灰、黄绿色、左侧导航的独立桌面外观，覆盖会话、记忆、用量、技能与插件、SnowLuma 及设置页面。
- 用户选定的 Q 环、消息箭头和星芒图标，以纯 SVG 为源，配套 PNG 和多尺寸 Windows ICO；用于窗口、托盘及安装器。
- 左上角动态图标可收展侧栏，收起后保留导航图标。支持键盘操作、状态记忆及减少动态效果偏好；收展不重建当前页面。
- 独立单实例、托盘恢复和窗口偏好。关闭或退出桌面不会停止机器人；“停机”仍进入机器人后台的停机流程。
- 桌面主题、刷新及托盘等偏好独立保存，聊天与模型等业务设置仍与原后台共享。

## 同步源码中的媒体修复

本标签同时包含已验证的后台源码修复；更新后台源码后生效，桌面安装器不携带这些后台模块。

- GIF 转视频保留原始帧率与帧间时序，按一个循环输出；最多接受 600 帧，保留尺寸、体积和处理时间限制。
- 消息图片 CDN 链接过期时，通过同一消息的 OneBot 图片 ID 刷新一次链接，继续保留请求取消及图片地址安全检查。

## 验证

- 桌面资源/API 转接、页面与设置、单实例和退出前保存自动化检查通过。
- 安装包及本机安装版的 40 个资源与源码匹配；没有打入机器人内核、配置、聊天数据、技能或依赖目录。
- 安装版图标、侧栏动画、空格键操作、偏好落盘及刷新恢复已实机验收。
- GIF 帧数、逐帧时间戳、总时长、奇数尺寸及超限处理检查通过。
- 失效链接刷新、真实看图工具到 MP4 的路径、请求取消及刷新后的地址安全检查通过。

源码复核命令：

```sh
npm run test:desktop-ui
npm run test:desktop-package
node test/gif-video-timing-test.mjs
node test/message-image-download-test.mjs
```

媒体测试需要 `ffmpeg` 和 `ffprobe` 位于当前命令行的 PATH 中；安装包检查需先运行 `npm run build:desktop-ui`。
