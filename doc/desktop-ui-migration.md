# 独立桌面外观迁移

目标：保留当前 0.4.2 聊天后台，迁移 0.5.1 的暖炭灰、黄绿色、左侧导航及控件视觉；原 Web 不换皮。

桌面是连接现有后台的独立 Electron 控制台，不启动另一套聊天内核，不复制账号配置或接管 SnowLuma。关闭/退出桌面只关闭桌面自己的资源。两端操作同一个机器人，模型、技能和暂停状态仍然共享；桌面外观、刷新偏好、开机启动和托盘设置单独保存。

| 阶段 | 完成条件 | 状态 |
| --- | --- | --- |
| 1 独立入口与外壳 | 独立资源与 API 转接；复用后台；主题隔离；原 Web 文件不改；实际渲染 | 已验收 |
| 2 页面迁移 | 会话、记忆、用量、技能插件、SnowLuma、全部设置及弹窗；保留原有入口与行为 | 已验收 |
| 3 交付 | 独立安装包；启动/单实例/托盘/退出；升级保留桌面偏好；Web 和机器人持续可用 | 已验收 |

实现入口：`desktop/`。复用现有 `ui/app/` 的业务脚本及主视图结构，视觉与外壳单独适配；不引入 0.5.1 内核、账号系统或自动更新器。桌面资源转接只监听 loopback，API 仍交给所选本机 0.4 后台，SSE 持续转发。迁移不要求更改原来的 Web 地址或重新登录 QQ。

视觉参考来自本机安装的 QQ Agent 0.5.1；不复制第三方图标、图片、账号资料及协议端。

## 构建与使用

先启动现有 0.4.2 后台，再打开桌面；默认连接 `http://127.0.0.1:3210`，可点顶部后台名称更换本机地址。`退出桌面` 不停机器人，`停机` 才进入原有停机流程。

```sh
npm run start:desktop-ui
npm run test:desktop-ui
npm run build:desktop-ui
```

独立安装器输出到 `dist-desktop/`。新的应用 ID、名称和安装记录不会覆盖原 QQ Agent 安装。桌面偏好位于 `%APPDATA%/QQ Agent Desktop/desktop-preferences.json`，不放进程序安装目录；不迁移或复制机器人数据。安装包只含桌面代码、原前端资源和图标，不含聊天内核、QQ/SnowLuma、技能配置、聊天数据或密钥。
