# 技能速查文档与按需读取

常驻提示只保留最短安全边界、发送协议及速查索引；角色卡与当轮数据继续单独传入。技能静态用法位于各自目录的 `QUICK_REFERENCE.md`，核心功能用法位于 `doc/core-guides/`。索引合并公共路径前缀，每行只列 ID、读取时机，非标准目录才逐项写路径。

```json
{
  "prompt": {
    "guide": {
      "file": "QUICK_REFERENCE.md",
      "when": "查询番剧、角色、声优或放送进度时",
      "priority": 58
    }
  }
}
```

模型调用 `read_skill_guide({"skillId":"bangumi-lookup"})` 后，完整文档以工具结果进入当前会话；后续技能调用复用已读取内容。宿主在技能工具执行前检查是否读过；不同会话/不同次运行不共享读状态，文档内容变化或技能重载后需要重新读取。文件缺失、关闭、不可用、非法编码、过大或越界时返回明确错误，不能绕过阅读直接使用技能。

扩展只允许固定文档名，核心只允许下述四个白名单文档，不接受模型传路径；文件真实路径须在对应目录内，大小上限 64 KiB。迁移不授予文件系统、命令或额外发送权限。已有硬命令、日额度、白名单、审批、发送队列均由原代码执行。

| 核心 ID | 文档与用途 |
| --- | --- |
| core-stickers | `doc/core-guides/core-stickers.md`：表情包、消息贴表情、拍一拍 |
| core-context | `doc/core-guides/core-context.md`：历史、引用、任务、记忆、跨会话发送 |
| core-media | `doc/core-guides/core-media.md`：图片、图库、音视频、合并转发、视频卡片 |
| core-web | `doc/core-guides/core-web.md`：联网查询与事实核验 |

核心用法通过同一个 read_skill_guide 工具按需查询；扩展技能仍保留“先读再执行”的宿主检查。核心 ID 为保留标识，不能被扩展占用。读取核心说明时返回当前表情频率或看图/搜索开关，避免把旧设置固化在文档中。

表情库不再为每次主会话预取快照、也不在角色卡后自动附目录；需要时先读 core-stickers，再 list_stickers 查询并选择真实 ID。各群人设不变。历史、引用绑定、有序任务及反应目标是当轮材料，继续保留，不能变成静态文档。

使用 `prompt.guide` 时不再重复注入其 `prompt.sections`。没有速查字段的旧扩展继续按原方式注入，保持兼容。动态 `promptSections(context)` 和主会话额外注入的当前身份/记忆仍会保留；它们属于当轮数据，不应移入静态文档。工具 schema 仍需随请求提供，参数说明不会因文档外置而自动消失。

本机迁移了 9 个 skills 和 2 个 plugins；两类均由 SkillManager 管理。插件开关保持原值，关闭项不会因建文档而启用。各群角色卡、历史条数和引用对象绑定均不调整。

迁移已安装扩展：`node scripts/migrate-skill-guides.mjs [QQ-Agent项目目录]`，之后重载扩展或重启。先备份清单，原用法逐字迁入文档；已迁移项不重复改写，遇到已有同名但未关联文档则拒绝覆盖。没有静态用法的未知扩展跳过；新增技能建议直接编写速查文档和读取时机。技能更新覆盖清单后，应手动核对并更新速查文档，避免沿用过时参数。

第一轮技能迁移将系统提示从 8,742 降至 3,730 字符。本次继续迁出核心用法并压缩索引，按当前开关实际为 837 字符，比 3,730 再减少约 78%；4 个核心索引和 9 个启用技能索引可用。此数字不含工具 schema、当轮数据和运行中读回的文档，后续启用动态扩展或管理员附加规则时会增长。

`npm run test:skill-guides` 覆盖单次运行先读后用、读取结果进入主会话、文件更新、技能重载/关闭、跨会话隔离、路径和大小边界；相关聊天回归使用本地 mock 验证。

普通闲聊不再携带全部技能用法，可减少初始上下文。首次使用技能会增加一次查询步骤；具体节省取决于该轮实际使用哪些技能，不等同于每轮总 token 固定下降。
