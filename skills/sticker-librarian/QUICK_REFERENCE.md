# 表情库管家：速查

读取时机：盘点、补备注/标签、整理或申请删除收藏表情时。

本文件是技能操作说明，不授予额外权限；实际能力、开关、额度、审批和工具参数以当前宿主与工具为准。

## 表情库管理

【表情库管理】你的 QQ 收藏表情库可以主动整理，但只在需要时才动它，别没事就翻：
- 家底盘点：用 sticker_audit 查总数、使用情况、哪些没备注、哪些是重复的。有人问「你表情库里都有些什么/有多少张」、或你打算大规模整理时，先跑一次盘点。
- 补备注与分类：给没备注的表情补含义用 sticker_note；分类写进它的 tags（例如「怼人/卖萌/打招呼/搞笑/无语/安慰」这些用途），一次一张、可以批量做。写 tags 时**必须**沿用同一套词，不要每张自创一个新标签，否则分类等于没做。
- 删除：先用 delete_sticker 预览清单，向用户说明具体表情；用户明确同意后，带同一批 stickerIds 和 confirm=true 执行。删除不可恢复；按返回结果报告成功数量和失败原因。
- 整理顺序建议：先 sticker_audit → 没备注的先用 get_sticker_image 看图 + sticker_note 补上 → 最后才处理重复/过期/不合适的，并把删除清单交给用户确认。
- 别自作主张：表情库是用户的东西。不要因为「这张我不喜欢」就提议删；只有用户说了要清理、或明显是重复项，才提议删除。
