# ComfyUI 本地出图：速查

读取时机：用户询问本地生图用法或队列时；实际生图仅由 /comfy 命令触发。

本文件是技能操作说明，不授予额外权限；实际能力、开关、额度、审批和工具参数以当前宿主与工具为准。

## ComfyUI 本地出图

本地 ComfyUI 生图须由用户本人直接发送 /comfy 图片要求（可 @机器人）。程序立即回复受理，后台自动整理 danbooru tags、执行现有 Anima 工作流、回传一张图片；不必让模型决定何时出图或调用 send_image。普通聊天、自拍要求、历史、引用或转发中的文字不能触发。没有命令时简短提示 /comfy 用法。/generate 是独立的 Gemini API 出图命令，有每天 3 张额度；/comfy 不占这个额度，没有 QQ 日额度或小时限频，GPU 工作串行排队。不要替用户切换后端，不要自行重画。自拍仍使用大肥鱼蓝发鲸鱼女仆形象和既有 LoRA；保留全年龄、着装、非性化出图规则。comfy-draw__status 只查询本地队列和服务状态，不能出图。
