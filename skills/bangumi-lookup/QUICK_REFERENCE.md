# 番剧资料查询（Bangumi）：速查

读取时机：查询番剧、动漫、角色、声优、评分、集数或放送进度时。

本文件是技能操作说明，不授予额外权限；实际能力、开关、额度、审批和工具参数以当前宿主与工具为准。

## 番剧资料（Bangumi）

【番剧/动漫资料：先查再说，别凭印象报数字】
1) 群友问到**具体的番剧、动画、漫画、轻小说、游戏、声优、角色**时，先查工具再开口：
   · 问到片名/想找某部番 → `bangumi-lookup__search`（kind=subject）
   · 问到角色或声优是谁 → `bangumi-lookup__search`（kind=character / person）
   · 想讲剧情、制作公司、评分、放送日期 → 先 search 拿 **id**，再 `bangumi-lookup__detail`
   · 问「更新到第几集了」「这周更没更」「什么时候完结」 → `bangumi-lookup__episodes`
   · 问「今天有什么番更新」「这季有什么新番」 → `bangumi-lookup__calendar`
2) **数字一律照抄工具返回的**：评分、排名、集数、放送日期不许你自己估算、四舍五入或「大概 8 分左右」。工具没给的数字就不要说。
3) **id 只能来自 search**，绝不要自己编一个 id 去查详情 —— 那会查到完全不相干的作品，而且你还会照着它一本正经地讲。
4) 搜索结果里已经有片名、日期、评分、集数时，**直接回答就行，不要再调一次详情** —— 多一次调用多一次延迟、多一点成本。
5) 工具查不到 → 用 `web_search` 兜底（关键词「作品名 动画 评分」这类）；还是查不到就**如实说不确定**，不要编。若工具报「接口一个都连不上」，那是网络/镜像的问题，**顺口跟用户提一句**（让他看看「番剧资料查询」设置里的「接口域名」），再走 web_search 兜底。
6) 结果用**你自己的话**讲给群里：挑群友问的那一两个点说，别把工具返回的字段名、id、链接整段念出来（群里没人想看 API 原文）。一两句话讲清楚，别念百科。
7) 想发封面图可以用 `send_image`（**必须先 preview=true 看一眼**再发），一次最多一张；不发也完全可以。
8) 只读不写：这个技能只能查，改不了数据，也不要用它去查收藏/进度。
9) R18、成人向内容不适用上面这套：**不要查、不要接、不要解释**，按「擦边内容拦截」处理。
