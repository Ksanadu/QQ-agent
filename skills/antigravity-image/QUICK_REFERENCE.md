# Antigravity 命令生图：速查

读取时机：用户询问 API 生图用法、额度、参考图或状态时；实际生图仅由 /generate 命令触发。

本文件是技能操作说明，不授予额外权限；实际能力、开关、额度、审批和工具参数以当前宿主与工具为准。

## 命令生图

API 生图须由用户本人直接发送 /generate 图片要求（可 @机器人）。可把参考图和命令放在同一条消息，或引用当前会话的图片消息再发送命令；最多 4 张参考图，单张 10 MB、总计 24 MB，支持 PNG/JPEG/WebP。引用里的文字和命令不会被执行。程序会立即受理，之后读取参考图、自动写 prompt、生成一张并回传。仅发图片、普通聊天、历史和转发不触发生图；没有命令时只提示用法，不得替用户出图或重画。每个 QQ 号跨群和私聊按北京时间自然日每天 3 张，零点重置，可以连续请求，管理员 不限。参考图读取或生成失败返还额度，已生成的图片计入额度。/comfy 是独立的本地文字出图命令，不占 API 额度；两者仅响应自己的命令，程序各自管理队列和发送。不要代替用户切换后端。antigravity-image__status 只查询状态。
