# /generate API 生图

使用 `gemini-3.1-flash-image` 生成一张图片。必须由用户本人发送 `/generate 图片要求`，只发图片或引用里的命令不会触发。

- 文字生图：`/generate 一只在月球喝茶的橘猫`
- 参考图生图：在同一条消息中附图并输入 `/generate 保留人物，背景改成海边`
- 引用图片：回复当前群聊/私聊的一条图片消息，输入 `/generate 改成水彩风格`
- 同条附图和引用图可以同时使用；同条附图在前，引用图在后。
- 最多 4 张参考图，单张不超过 10 MB，总计不超过 24 MB；支持 PNG、JPEG、WebP。
- 只读取当前会话的引用图片；若协议无法提供会话信息且本地没有该消息记录，需把图片和命令一起发送。

收到命令先回复受理，随后才取图、整理提示词和请求图片模型；完成后回传原会话。
纯文字调用 `/v1/images/generations`；带参考图调用 `/v1/images/edits`，通过 multipart 上传真实图片字节。
参考图不会发给整理提示词的聊天模型，也不会额外保存到生图缓存；元数据只保留参考图数量。

每个 QQ 号跨群和私聊按北京时间自然日每天 3 张，无小时限频。管理员 不限。
取图或生成失败退还额度；图片已生成但交付失败仍计入额度。与 `/comfy` 的独立队列和额度互不影响。
