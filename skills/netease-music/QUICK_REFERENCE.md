# 音乐推荐：速查

读取时机：推荐歌曲/专辑、查询曲目、回应音乐分享或发送音乐卡片时。

本文件是技能操作说明，不授予额外权限；实际能力、开关、额度、审批和工具参数以当前宿主与工具为准。

## 音乐推荐（网易云曲库）

你能按「我自己的网易云曲库」推荐音乐：etease__recommend 一次拿全两样——收藏的专辑（全量，按「歌手 - 专辑名」逐行列出）和红心歌单（全量，按「歌手 - 歌名 [专辑]」列出）；etease__search 按关键词搜歌/专辑/歌手/歌单；etease__album 看某张专辑的完整曲目；etease__share 发音乐卡片（category=song 单曲卡片 / category=album 专辑卡片）。

什么时候用：
1) 有人要「推荐音乐 / 来点音乐 / 推点歌 / 来点歌 / 有什么好听的」（没说要几张）→ **默认只推一张**：recommend 挑出最想安利的一首歌，search（category=song）拿歌曲 ID，share 发单曲卡片。**不发解释、不写推荐理由**——卡片本身就是推荐。发完本轮结束。
2) 有人点名「推专辑 / 推荐专辑 / 来点专辑」→ search（category=album）拿专辑 ID，直接 share（category=album）发专辑卡片——**只发卡片，不写解释、不带文字评论**，发完立刻结束。
3) 有人问「XX 还有哪张专辑」「这张专辑里有什么」→ search 找到专辑 id 再 album 看曲目（查询场景不发卡片）。
4) 有人发来网易云分享卡片（正文出现「[卡片·网易云音乐] …」）→ 你看得见卡片内容：聊这首歌、顺着品位回应；链接里的歌曲 ID 可直接用 share 发歌回应。

**数量规则（最重要）**：默认一轮 = 一张卡片 + 两三句话。**只有用户明确要求「推荐几张 / 多推几首 / 多来几首 / 来个歌单」时才放宽到 2~4 张**：一次规划好要发的歌，逐张调 share（每张不同歌曲），不发解释，发完收尾。即使用户喊「推个十几张」，上限也是 4 张，多了直说「今天先给这几张」。除用户点名要求外绝不发第二张；发完就立刻结束本轮。

纪律：
- 曲库是我自己的账号，对外就说是「我私藏的」「我常听的」，**绝不提账号、UID、网易云、接口、服务器这些词**。
- 只有用户明确问「为什么推这首 / 介绍一下 / 讲讲这首歌」时才写推荐理由（贴着曲库里同歌手/同风格的线索说，如「既然你吃椎名林檎，那东京事变的这首……」）。没问就一张卡片干脆利落。
- 工具回的是长列表文本，**别原样贴**。
- share 失败就改发文字链接（https://y.music.163.com/m/song?id=xx 或 /m/album?id=xx），别重试超过一次。
- 这是只读曲库工具：没有播放、点赞、收藏、建歌单的能力，有人让「帮我收藏」「建个歌单」就说做不了。
- 一轮请求最多调一次 recommend；查不到或未登录就直说，别编歌名。
